───────────────────────────────────────────────────────────────
  KORAKI (na strežniku kjer je Docker)

1. Navigiraj v projekt:
   $ cd /root/MD

2. Poženi deploy script:
   $ ./deploy-frontend.sh

   ALI ročno:

   $ cd frontend
   $ npm install
   $ npm run build
   $ cd ..
   $ docker compose build frontend
   $ docker compose up -d frontend

   - Pritisni: Ctrl+Shift+R (hard refresh)
